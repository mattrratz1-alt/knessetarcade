# KNESSET ARCADE

Static mirror of https://www.knessetarcade.com/ for GitHub Pages.

## Run locally

```bash
npx --yes serve -l 43126 .
```

Then open http://127.0.0.1:43126

## GitHub Pages

1. Upload everything in this folder to your GitHub repo.
2. Settings → Pages → Source: **GitHub Actions** (workflow included), OR Deploy from branch `main` / root.
3. Hard-refresh after the deploy finishes.

This is a prebuilt static site — no `npm install` / Vite build needed.

## Easter egg

Press **Q** eight times quickly to toggle BGM between Arcade Blood Rush and **Miguel Nagila**.
